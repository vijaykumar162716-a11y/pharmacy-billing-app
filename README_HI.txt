Pharmacy Billing App — Android project source

यह Android Studio project source है, APK फ़ाइल नहीं।

APK बनाने के लिए:
1. Android Studio वाले कंप्यूटर पर यह ZIP Extract करें।
2. Android Studio में इस folder को Open करें।
3. Gradle sync पूरा होने दें (internet और Android SDK आवश्यक हैं)।
4. Build > Build APK(s) चुनें।

ध्यान दें:
- यह वर्तमान browser prototype को Android WebView में खोलता है।
- Photo upload chooser का wrapper जोड़ा गया है, लेकिन supplier bill के सभी आइटमों को विश्वसनीय रूप से OCR से Purchase Entry में भरने की सुविधा अभी production-ready/tested नहीं है।
- Cloud Sync, Windows app, secure backup, GST/accounting validation और production testing बाकी हैं।
- अभी इसे असली दुकान के live stock/billing के लिए बिना परीक्षण इस्तेमाल न करें।
